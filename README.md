# daedalus

A spec-driven development project scaffolded with [Spec Kit](https://github.com/github/spec-kit).

## Overview

This repository is structured around a spec-first workflow: features begin as
specifications and plans under `.specify/`, which then drive implementation.

## Getting started

The project uses Spec Kit with the Claude integration. Key directories:

- `.specify/` — specs, plans, templates, the project constitution, and helper scripts
- `.claude/skills/` — Spec Kit workflow skills (specify, plan, tasks, implement, …)
